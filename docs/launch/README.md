## Platform rules baked into these drafts

- X: link in the body is fine now (no link penalty since mid-2025 per Nikita Bier/Musk); native media + full description; end on a question; answer replies in the first hour. Reply and DM-share are the heavy weights.
- LinkedIn: long dwell wins; link in the first comment, not the body; substantive comments; reply within 30 min.
- Reddit: story not pitch; one link at the end; no upvote asks; reciprocity (comment on other projects first).
- Product Hunt: the first comment (maker story) matters more than the description; captioned product screenshots over brand art; engagement over hunters.
- YouTube: search-indexed, so keyword-rich title + link up top; burned-in captions on Shorts.
